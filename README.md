# 🛒 Grocery Management System

### A Full-Stack Web Application for Smarter Grocery Management

A web application built to simplify grocery product and category management with an interactive dashboard, stock monitoring, and easy-to-use CRUD operations.

## ✨ Key Features

- 📊 **Dashboard** — View key grocery and stock information.
- 📦 **Product Management** — Add, view, edit, and delete products.
- 🔍 **Product Search & Sorting** — Find products easily.
- ⚠️ **Stock Monitoring** — Identify low-stock products.
- 🗂️ **Category Management** — Create, search, edit, and delete categories.
- 🔔 **Notifications** — Get feedback for successful actions and validation.
- 🎨 **User-Friendly UI** — Clean interface with a consistent green theme.

## 🚀 Getting Started

### Prerequisites

- Node.js and npm
- Angular CLI
- .NET SDK
- Microsoft SQL Server
- Visual Studio or VS Code

### 1. Clone the Repository

```bash
git clone https://github.com/Meghna2004p/GroceryManagementSystem.git
cd GroceryManagementSystem
```

### 2. Configure the Database

Update the `DefaultConnection` connection string in `GroceryAPI/appsettings.json` to match your SQL Server instance.

### 3. Run the Backend

Open the `GroceryAPI` project in Visual Studio and run it. Confirm the API URL and Swagger URL from your local launch settings.

### 4. Run the Frontend

Open a terminal in the `GroceryUI` folder and run:

```bash
npm install
ng serve
```

Open **http://localhost:4200** in your browser.
